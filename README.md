# 🎒 Smart Lost & Found Portal

A modern web application that helps students and staff report, search, and claim lost and found items within a college campus. The platform provides a simple and secure way to connect people who have lost belongings with those who have found them.

# 📖 Project Overview

The Smart Lost & Found Portal is designed to simplify the process of reporting and recovering lost items on campus. Users can report lost or found items, browse available items, search using keywords, and submit claims. An administrator can manage reports and monitor activities through an admin dashboard.

This project demonstrates Full Stack Web Development concepts including frontend design, backend logic, authentication, database management, and deployment.

# ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/sriram-128/smart-lost-found.git
```

### Navigate to the project folder

```bash
cd smart-lost-found
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```

# 🔄 Workflow

1. Register a new account.
2. Login securely.
3. Report a lost item.
4. Report a found item.
5. Browse all available items.
6. Search using keywords.
7. Submit a claim request.
8. Administrator manages all reports.

- Simplify reporting of lost and found items.
- Reduce manual searching.
